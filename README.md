# project-tidy

一个给 pi 用的技能：检查并整理一个项目的文档基建。

它管六件事：版本控制、`AGENTS.md`、`TODO.md`、历史记录目录、生成物跟源码分开、手写备份文件。

核心想法是把一个项目里的文档分成三类，各管各的：

| 文件 | 只装什么 | 一句话判据 |
|---|---|---|
| `AGENTS.md` | 规矩 | 换谁来都必须照做 |
| `TODO.md` | 状态 | 做完就该删掉 |
| `记录/YYYY-MM.md` | 事实和理由 | 以后只会被查，不会再被改 |

再加一类**模块说明**（`*_说明.md`）：按主题写、跟着模块走、只追加。

## 里面有什么

- `SKILL.md` —— 技能本体：怎么体检、怎么出方案、按什么顺序改、做什么不做什么。
- `references/标准.md` —— 这套规矩的完整原文，可以直接复制进某个项目的 `AGENTS.md`。
- `references/文件模板.md` —— `TODO.md`、记录、忽略清单、`AGENTS.md` 的骨架。
- `scripts/体检.sh` —— 只读体检脚本：一个文件都不改，只报告现在的样子。

## 怎么装

把整个目录拷到 pi 的技能目录：

```bash
cp -r project-tidy ~/.pi/agent/skills/
```

Windows 上是 `C:\Users\<你>\.pi\agent\skills\project-tidy`。

装完之后，在一个想整理的项目里让 pi 干活，它会自己认出这个技能；也可以直接说“整理一下这个项目的文档”。

## 怎么用

体检脚本可以单独跑，只读，不改任何东西：

```bash
bash scripts/体检.sh <项目路径>
```

大项目上嫌慢就调小深度：

```bash
DEPTH=3 MD_LIMIT=100 bash scripts/体检.sh <项目路径>
```

脚本依赖 bash 和 GNU find / xargs。Windows 上 git-bash 自带。

## 边界

- 只管文档、忽略清单，以及删手写备份文件。**不碰代码。**
- 要动 `AGENTS.md`、或者一次要改超过三个文件，会先出方案等确认。
- 一处上限都没定死：`AGENTS.md` 60 行、`TODO.md` 120 行是默认值，装不下会照实说，不会偷偷放宽。
